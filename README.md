# Claude HUD

Маленькая полупрозрачная плашка для macOS, которая **всегда висит поверх окон** и показывает лимиты Claude:

- **Сессия (5 ч)** — сколько процентов съедено и когда сброс
- **Неделя** — то же для недельного лимита

Цвет полосы меняется: зелёный → жёлтый (60%) → красный (85%).

**Ещё умеет:**
- **Метка темпа** — белая чёрточка на полосе показывает, сколько времени окна уже прошло. Цветная часть обогнала чёрточку → тратишь быстрее, чем идёт время.
- **Прогноз** — «в этом темпе кончится ≈ 15:40» или «хватит до сброса».
- **Уведомления** при 80% и 95% и когда лимит сбросился.
- **Иконка в строке меню** — две мини-полоски (5 ч и неделя), по желанию с процентами. По клику — подробный блок, включая недельные лимиты по моделям (Opus / Sonnet), если они есть у твоего тарифа.

```
┌──────────────────────────────┐
│ Сессия · 5 ч             37% │
│ ███████░░░░░░░░░░░░░░░░░░░░░ │
│ сброс через 4ч 48м · 16:20   │
│ Неделя                   16% │
│ ███░░░░░░░░░░░░░░░░░░░░░░░░░ │
│ сброс через 6д 15ч · 14 июл  │
└──────────────────────────────┘
```

Есть компактный режим в одну строку: `5ч ▬▬ 37% 4ч 48м │ 7д ▬ 16% 6д 15ч`

## Как это работает

Приложение берёт токен, который **Claude Code** сохраняет после входа (Связка ключей, запись `Claude Code-credentials`), и раз в 2 минуты спрашивает `https://api.anthropic.com/api/oauth/usage` — тот же запрос, что делает команда `/status` в Claude Code. Токен никуда, кроме api.anthropic.com, не уходит.

> ⚠️ Это неофициальный эндпоинт: Anthropic может его поменять. Если плашка начнёт показывать ошибку — проверь issues.

## Установка

**Нужно:** macOS 13+, установленный [Claude Code](https://docs.claude.com/en/docs/claude-code), в котором ты вошёл через подписку (`claude` → `/login`).

### Из релиза
1. Скачай `ClaudeHUD.zip` из [Releases](../../releases), распакуй, перетащи в «Программы».
2. Первый запуск: правый клик → **Открыть** (приложение не нотаризовано). Или:
   `xattr -dr com.apple.quarantine /Applications/ClaudeHUD.app`
3. macOS спросит доступ к Связке ключей для `Claude Code-credentials` → **Разрешать всегда**.

### Из исходников
```bash
git clone https://github.com/danchiKNuevaYol/Claude-Code-limits.git
cd Claude-Code-limits
./build.sh install
```
Для быстрой проверки без сборки .app: `swift run`.

## Управление

Всё — через иконку с двумя полосками в строке меню **или правым кликом по самой плашке** (удобно, если иконка спряталась за вырезом экрана):

| Пункт | Что делает |
|---|---|
| Показать / спрятать плашку | `⌘H` |
| Компактный / подробный вид | `⌘M` |
| Пропускать клики сквозь плашку | плашка не мешает кликать по тому, что под ней |
| Прозрачность | 100 / 80 / 60 / 40 % |
| Вернуть в угол экрана | если потерял её |
| Показывать проценты в строке меню | или только иконка-полоски |
| Уведомления при 80% и 95% | вкл/выкл |
| Запускать при входе | автозапуск (приложение должно лежать в «Программах») |

Плашку можно перетащить мышкой куда угодно — место запоминается. Она видна на всех рабочих столах и поверх полноэкранных приложений.

## Если что-то не так

| Сообщение | Что сделать |
|---|---|
| «Нет входа в Claude Code» | запусти `claude` и залогинься |
| «Токен истёк» | просто запусти `claude` — он обновит токен, плашка подхватит сама |
| «Слишком часто спрашиваем» | сервер ответил 429; приложение само подождёт |

Можно передать токен вручную: `CLAUDE_CODE_OAUTH_TOKEN=... swift run`.
